Generative UI の仕組み

  • 質問すると、モデルがツール（記事検索・集計・原文参照）を呼ぶ
  • 回答は文章だけでなく、部品（記事カード・時系列・グラフ）で返る
  • モデルは HTML を書かない：部品カタログから選び、実データはコードが埋める
一次情報レーダー探検UI4 / 8

部品は記事カード／時系列／媒体一覧／統計チップ／見立てパネル／トーンチャート。LLM が生 HTML を作らないので、表示は決定的に再現できる。

自動生成と検証ゲート

  • Cron が1時間に1回、収集DBの新着を検知し、出来事ごとに畳む
  • LLM が出来事の画面を生成し、検証ゲートが出典URL・数値の実在を確認する
  • 通過した画面だけが D1 に保存され、開いている画面へ届く
