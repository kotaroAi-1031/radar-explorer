課題と狙い

  • 一次情報は散らばっている：記事が世界中の媒体に分散し、追い切れない
  • 監視する問いは6つ：①中東（イスラエル・ガザ・イラン） ②米国の対中南米・対麻薬政策 ③日本は経由地としてどう見られているか ④テック界隈のパワー構造 ⑤AI の一次情報 ⑥セキュリティ実務
  • 集め方：収集元は GDELT（世界の報道を集める公開データベース）。専用の収集プログラムが問いごとに記事を集め、データベースに貯めている
  • 要約だけでは出典が消える：誰の・いつの報道か分からない情報は、判断に使えない
  • 狙い：自動で集めた記事を「出典つきの部品」で読み、出来事ごとに追えるようにする

Generative UI の仕組み

  • 質問すると、モデルがツール（記事検索・集計・原文参照）を呼ぶ
  • 回答は文章だけでなく、部品で返る。部品は6種類：記事カード／時系列／出典リスト／統計チップ／見立てパネル／トーンチャート
  • 見立て＝問いごとに持つ「現時点の情勢判断」。トーン＝記事の論調を表す数値で、トーンチャートはその推移
  • モデルは HTML を書かない：部品カタログから選び、実データはコードが埋める
一次情報レーダー探検UI8 / 14

部品は記事カード／時系列／媒体一覧／統計チップ／見立てパネル／トーンチャート。LLM が生 HTML を作らないので、表示は決定的に再現できる。

自動生成と検証ゲート

  • Cron が1時間に1回、収集DBの新着を検知し、出来事ごとに畳む（クラスタリング＝同じ出来事の記事をひとまとめにすること）
  • LLM が出来事の画面を生成し、検証ゲートで確かめる
  • 検証ゲート＝画面に出る出典URLや数値が実データに存在しなければ弾く仕組み。通過した画面だけが D1（画面の保存先）に保存され、開いている画面へ届く

無料枠の運用

  • 外部の AI API は使わない：AI は Cloudflare Workers AI 上のモデル（Llama 4 Scout 17B／Mistral Small 3.1 24B／Llama 3.1 8B）のみで、binding 経由で完結する
  • neurons（ニューロン）＝ AI の利用量を数える単位。天井は Workers AI の 10,000 neurons/日で、実質の上限はここだけ
  • 画面1件は実測 約77 neurons ＝ 1日およそ130件分。毎日 00:00 UTC（日本時間 9:00）にリセットされる
  • 自動生成は Llama 4 Scout 17B、チャットは Mistral Small 3.1 24B
  • 6,000 で軽いモデルに落とし、8,000 で自動生成を止める（日次カウンタで管理）
  • 70B は使わない：役割分担は実測で決めた
